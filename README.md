# gdg-cloud-thessaloniki/.github

Το αποθετήριο αυτό περιέχει τα κοινά αρχεία κοινότητας και υγείας (community health files) του οργανισμού **GDG Cloud Thessaloniki** στο GitHub. Το GitHub τα εφαρμόζει αυτόματα σε κάθε αποθετήριο του `github.com/gdg-cloud-thessaloniki` που δεν διαθέτει δικά του.

This repository holds the shared community health files of the **GDG Cloud Thessaloniki** organization on GitHub. GitHub applies them automatically across all repositories under `github.com/gdg-cloud-thessaloniki` that do not provide their own.

| Αρχείο / File | Περιγραφή / Description |
|---|---|
| [`profile/README.md`](profile/README.md) | Η κεντρική σελίδα προφίλ του οργανισμού / The organization profile landing page |
| [`SECURITY.md`](SECURITY.md) | Πολιτική ασφάλειας, αποποίηση ευθύνης και αναφορά ευπαθειών / Security policy & vulnerability reporting |
| [`LICENSE`](LICENSE) | Προεπιλεγμένη άδεια χρήσης / Default organizational license |

## 🇬🇷 Χαρακτήρας Αποθετηρίων & Πνευματικά Δικαιώματα

Το GDG Cloud Thessaloniki είναι μια εθελοντική κοινότητα. Τα αποθετήρια αυτού του οργανισμού λειτουργούν ως αρχείο και χώρος διαμοιρασμού:
- Κώδικα επιδείξεων (demos) και hands-on εργαστηρίων.
- Αρχείων διαφανειών και παρουσιάσεων (slide decks).
- Εργαλείων και παραδειγμάτων αρχιτεκτονικής cloud.

### Πνευματική Ιδιοκτησία & Δημιουργοί
- **Δεν διεκδικούμε την κυριότητα του κώδικα:** Ο κώδικας και το εκπαιδευτικό υλικό που παρουσιάζονται στις συναντήσεις μας ανήκουν στους αντίστοιχους εισηγητές, ομιλητές και αρχικούς δημιουργούς τους (upstream projects).
- **Μη εμπορικός χαρακτήρας:** Η φιλοξενία τους εδώ γίνεται για σκοπούς αρχειοθέτησης, μελέτης και εκμάθησης.
- **Εκτέλεση με δική σας ευθύνη:** Ο κώδικας δεν συντηρείται ενεργά για παραγωγική χρήση (production). Συνιστάται πάντα η εκτέλεση σε απομονωμένα δοκιμαστικά περιβάλλοντα (sandboxes).

## 🇬🇧 Repositories Scope & Intellectual Property

GDG Cloud Thessaloniki is a volunteer-led tech community. The repositories hosted under this organization serve as a showcase and knowledge hub for:
- Demonstration code (demos) and hands-on workshop materials.
- Presentation slides and speaker assets.
- Cloud architecture samples and IaC blueprints.

### Authorship & Third-Party Code
- **No Claim of Ownership:** GDG Cloud Thessaloniki does not claim ownership or intellectual property of speaker-contributed projects or upstream open-source code. Copyright belongs strictly to their respective authors.
- **Educational Context:** Projects are mirrored or hosted here solely for academic review, community learning, and technical demonstration.
- **Execution at Own Risk:** Demonstration code is not maintained as production software. Users should exercise caution and run samples only in isolated test environments.
